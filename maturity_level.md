# Low
- [ ] Code is available
- [ ] Documentation is available

# Medium
- [ ] Documentation covers all the project.
- [ ] Build process is repeatable and consistent.
- [ ] Unitary tests and non regression tests are implemented.

# High
- [ ] Build process is fully integrated into the workflow.
- [ ] Security policy in place.
- [ ] Tests for known vulnerabilities.
- [ ] Embed security testing as part of the development and deployment processes.
- [ ] Code coverage is above 70%.
- [ ] Security fuzzing tests.
